## 📞 Need Help?

### Common Questions

**Q: How do I run the app?**
A: Open terminal, go to `react-app/`, run `npm run dev`

**Q: How do I change text/content?**
A: Edit files in `src/pages/` - changes auto-reload

**Q: How do I change colors?**
A: Edit `src/styles/App.css` - CSS variables at top

**Q: How do I add a page?**
A: Create new `.jsx` file in `src/pages/`, add route in `App.jsx`

**Q: How do I deploy?**
A: Build with `npm run build`, upload `dist/` folder
