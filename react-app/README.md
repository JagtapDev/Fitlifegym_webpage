# FitLife Gym - React Application

A modern, responsive fitness gym website built with React, Vite, and Bootstrap.

## Features

- ✨ Modern and responsive UI
- 🏋️ Multiple service pages (Weight Loss, Weight Gain, Nutrition, Personal Training, etc.)
- 📱 Mobile-friendly design
- ⚡ Fast performance with Vite
- 🎨 Beautiful dark theme with gold accents
- 📊 BMI Calculator with real-time calculations
- 📧 Contact form for inquiries
- 🛣️ Client-side routing with React Router

## Installation

1. Navigate to the project directory:
```bash
cd react-app
```

2. Install dependencies:
```bash
npm install
```

## Running the Application

### Development Mode
```bash
npm run dev
```
The app will open in your browser at `http://localhost:3000`

### Production Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

## Pages

- **Home** - Landing page with services overview
- **Weight Loss** - Custom weight loss programs
- **Weight Gain** - Muscle building programs
- **Nutrition** - Nutrition planning and counseling
- **Personal Trainer** - One-on-one coaching
- **BMI Calculator** - Calculate and track BMI
- **Pricing** - Membership plans
- **Contact** - Contact form and information
- **Group Classes** - Fitness classes schedule
- **Kids & Teens Fitness** - Youth programs
- **Online Coaching** - Remote training options
- **Rehabilitation** - Injury recovery programs

## Technologies Used

- **React 18** - UI library
- **Vite** - Build tool and dev server
- **React Router v6** - Client-side routing
- **Bootstrap 5** - CSS framework
- **CSS3** - Custom styling

## Customization

### Colors
The application uses a dark theme with gold accents. Customize colors in `src/styles/App.css`:
- Primary Dark: `#111316`
- Secondary Dark: `#181a1b`
- Accent Yellow: `#ffc107`
- Text Light: `#e0e0e0`

### Images
Replace images in the `public/img` directory with your own gym images.
